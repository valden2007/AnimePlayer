# AnimePlayer — десктопный аниме-плеер

Онлайн-поиск и воспроизведение аниме на русском языке (озвучка AniLibria). Без ключей и платных сервисов.

## Запуск

### Windows
Дважды кликните `Запустить.bat` в корне папки. Скрипт сам проверит Node.js, при первом запуске выполнит `npm install` и запустит приложение без чёрного окна консоли. Повторные запуски пропускают установку.

### Linux / macOS
```bash
chmod +x start.sh
./start.sh
```

Требование: Node.js 18+ (https://nodejs.org/).

## Сборка portable .exe
```bash
npm run build
```
Результат в папке `dist/` (electron-builder, target portable).

## Структура
- `main/` — main-процесс Electron, IPC, сетевые запросы к API (обход CORS).
- `renderer/` — интерфейс (HTML/CSS/JS), плеер (hls.js).
- `providers/` — слой провайдеров с единым интерфейсом.
- `assets/` — иконка.

## Провайдеры
- `anilibria` — AniLibria API v1 (anilibria.top). Основной: поиск, каталог, эпизоды, HLS-потоки.
- `shikimori` — Shikimori API. Резервный: метаданные и поиск, без потоков.

Интерфейс провайдера: `search(query)`, `getTitle(id)`, `getEpisodes(id)`, `getStream(episodeId, quality)`, `getCatalog(opts)`, `getGenres()`, `getYears()`. При падении активного провайдера Manager автоматически пробует следующий и показывает понятную ошибку.

Добавить провайдера: создать файл в `providers/`, унаследовать `BaseProvider`, реализовать методы, зарегистрировать в `providers/manager.js`.

## Функционал
- Поиск на русском/английском с debounce и подсказками.
- Главная: новинки, популярное, фильтры по жанру и году.
- Страница тайтла: постер, описание, жанры, год, статус, эпизоды.
- Плеер: play/pause, перемотка, громкость, fullscreen, выбор качества 480/720/1080, горячие клавиши (пробел, ←/→, F, M), автопереход на следующую серию.
- Избранное, продолжение просмотра, история поиска (localStorage).
- Тёмная тема, скелетон-загрузки, обработка ошибок сети.

## Настройки и озвучки
- В правом верхнем углу кнопка ⚙ открывает настройки.
- Приложение работает на AniLibria (одна озвучка).

## Известные ограничения
- Потоки AniLibria могут быть недоступны в некоторых регионах (блокировки).
- Shikimori-провайдер не отдаёт видеопотоки.
- HLS воспроизведение зависит от hls.js и кодеков системы.
- При первом запуске требуется интернет для `npm install`.
